# VetParser — многоагентный парсер данных для интеллектуальной ветеринарной системы

Многоагентный программный комплекс для автоматизированного сбора, обработки и сохранения данных о ветеринарных клиниках, услугах, ценах, отзывах и геоданных из различных информационных источников.

Проект разработан в рамках дипломного проекта по направлению «Информационно-аналитические системы безопасности» и обеспечивает информационную базу для интеллектуальной системы поддержки выбора ветеринарной клиники и сопровождения владельцев домашних животных.

## Возможности

- **Многоагентность** — каждый источник обрабатывается отдельным агентом; агенты работают параллельно и могут передавать задания друг другу.
- **Многопоточность** — пул потоков и процессов для параллельной загрузки и обработки данных.
- **Временное хранилище** — очередь заданий и кэш на Redis (с fallback на SQLite).
- **Передача заданий** — агент может сформировать подзадачу (например, «собрать отзывы о найденной клинике») и передать её другому агенту.
- **API и HTML** — поддержка официальных API (Яндекс.Карты, 2ГИС, OpenStreetMap) и парсинга HTML-страниц (Zoon, ProDoctorov, Flamp, сайты клиник).
- **JS-рендеринг** — Playwright для сайтов с динамической загрузкой контента.
- **Обработка данных** — очистка, нормализация, дедупликация, валидация, обогащение.
- **Устойчивость** — retry, dead-letter queue, изоляция отказов, graceful shutdown.
- **Планировщик** — периодическое обновление данных по расписанию.
- **Расширяемость** — новый источник добавляется без изменения ядра системы.
